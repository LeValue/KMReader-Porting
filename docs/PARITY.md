# Matrice di parità

Il riferimento è [kmworks/kmreader](https://github.com/kmworks/kmreader/tree/e2b35f8796cc830fc6e7464e161b2172d8f916e9).
Le voci aperte riguardano le prossime versioni di KMReader per Android e Windows.

| ID | Area | Lavoro rimanente |
|---|---|---|
| A-01 | Azioni upstream | Inventariare le differenze in navigazione, catalogo, dettagli, lettori, offline e statistiche. |
| A-02 | Server e chiavi API | Confrontare modifica e protezione dei server, permessi, identificazione delle chiavi e capacità delle estensioni Komga. |
| A-03 | Integrazione di sistema | Definire monitoraggio cartelle, prelettura, indicizzazione, notifiche, azioni rapide e finestre multiple. |
| F-01 | Catalogo | Completare ordinamenti, filtri annidati, selezioni oltre la prima pagina e mantenimento delle preferenze. |
| F-02 | Liste offline | Completare liste speciali e On Deck con ordinamento, indicazione di indice parziale e isolamento per account. |
| F-03 | Copertine | Completare la gestione delle copertine delle liste fornite dalle estensioni del server. |
| F-04 | Condivisione | Uniformare esportazione, pagine singole delle doppie pagine, annullamento e file temporanei. |
| F-05 | PDF offline | Completare il comportamento dopo riavvio e con file grandi o cifrati, contenendo memoria e spazio dei derivati. |
| F-06 | EPUB | Rifinire impaginazione mista, scritture CJK, font, reflow, locatori e strumenti di selezione. |
| F-07 | Download e spazio | Migliorare le indicazioni per quota, download attivi, cache rimovibile e ripresa dopo interruzioni. |
| F-08 | Aggiornamenti live | Completare l'invalidazione per metadati, copertine, liste, progresso e attività dopo la riconnessione. |
| F-09 | Statistiche e cronologia | Allineare filtri, indice offline completo e risposte dei server con estensioni. |
| F-10 | Interfaccia | Allineare dettagli, sidebar, libreria offline, tipografia e controlli dei lettori, rispettando le convenzioni di piattaforma. |
| F-11 | Preferenze | Allineare valori iniziali, unità e precedenza fra impostazioni globali, preset e preferenze del volume. |
| F-12 | Lingue e accessibilità | Completare le traduzioni, il ridimensionamento del testo, i nomi accessibili e la navigazione da tastiera. |
| F-13 | Kindle | Estendere gestione e sincronizzazione per formati ed edizioni privi di mappatura verificabile. [Limiti attuali](KINDLE_LIBRARY_MANAGEMENT.md) |
| FUT-01 | Modelli, OCR e traduzione | Definire l'estensione della libreria dei modelli e delle funzioni di traduzione. |
