KMReader 0.6.1 development preview for Android and Windows.

For most current Android phones, download `KMReader-0.6.1-android-arm64-preview.apk`.
Older ARMv7 devices use `KMReader-0.6.1-android-armv7-preview.apk`; x86_64 devices
and emulators use `KMReader-0.6.1-android-x64-preview.apk`. Each is a complete
application; install one. Android 7.0+ is supported.

The retained certificate, Preview application ID and increasing version code 8
allow updating earlier Preview builds while preserving accounts, downloads and
reading data. For Windows 10/11 x64, extract the entire
`KMReader-0.6.1-windows-x64-preview.zip` and run `KMReader/kmreader.exe`.
The MSVC runtime is included; the Windows bundle is not Authenticode signed.

This update includes all 0.6.0 features and corrects EPUB layout handling:

- Fixed-layout publications retain authored fonts, colors and positioned content.
  Automatic spreads respect publisher metadata. Settings expose page choices and
  omit typography controls that would change the authored composition.
- Body-declared vertical CJK writing modes are detected before pagination, while
  spine reading order stays independent of the text's inline direction.
- Continuous vertical text accepts horizontal scrolling and preserves reading
  locators. CFI and fragment navigation reveal the selected content, and font
  changes retain the visible CFI anchor without writing new reading progress.
- Large vertical text retains a visible CFI anchor through font changes and
  viewport reflow; subsequent page turns advance the actual visible character.
- The first real scroll updates progress even after an initial no-op programmatic
  scroll; continuous reading only reports completion at the physical document end.

Source: `@SOURCE@`. Publication requires successful source-matched Android and
Windows build/native integration jobs. Embedded build provenance binds both
application packages to that exact revision. The exact APKs are checked for SHA256,
retained signing certificate, package/version/architecture, non-debuggable mode
and 16 KiB alignment. Uploaded asset digests and `SHA256SUMS.txt` cover all files.

This remains a development preview. Full upstream parity, additional OCR models,
exact translated typesetting, comic curl, some mixed-layout EPUB cases, OS
integrations and physical-device performance acceptance remain in progress.
See `docs/PARITY.md` and `docs/VALIDATION.md`. Download access requires a GitHub
account authorized for this private repository.
