# KMReader 0.8.14 preview

EPUB curl prepares the current page and its neighbours, including GPU draw work,
after every completed or canceled gesture and after direct navigation/reflow.
Dragging within a chapter previews these retained images without navigating or
changing the reading position. Navigation commits on release. Chapter boundary
turns wait for release before replacing the source iframe. Focus loss, canceled
preparation and suspended input always retire the gesture.

Text settings remove the retained native WebView from modal composition. Controls
edit a local draft; closing the panel applies the final settings in one reflow.
The native view, viewport and reading location are preserved.

The front of the curling page attenuates projected shadows over its roll radius,
removing the bright seam caused by the former fixed two-pixel depth cutoff.

Comic curl compares fitted paper surfaces. Compatible pages retain curl; a turn
between substantially different aspect ratios or single/double layouts uses a
continuous slide, keeping both images at their proper proportions and position.
Source image resolution alone does not change the animation.

Regression checks cover first-drag texture reuse, current/destination pixels,
cancel/retry, focus loss, stalled snapshot decoding, LTR/RTL and spreads. A pixel
control reproduces the old front-shadow cutoff. Native integration checks include
scrolling settings with the browser offstage, applying one final draft and
retaining the same native view. Physical-device display FPS is not established by
these checks.
