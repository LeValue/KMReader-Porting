KMReader 0.6.0 development preview for Android and Windows.

Download `KMReader-0.6.0-android-preview.apk` for Android 7.0+ (ARMv7, ARM64 or x86_64).
This optimized, signed build updates **KMReader Preview** in place and retains its
accounts, downloads and reading data. It uses the same application ID and retained
development certificate as 0.5.0. The first debug app remains a separate installation.

For Windows 10/11 x64, download `KMReader-0.6.0-windows-x64-preview.zip`, extract the
whole folder and run `KMReader/kmreader.exe`. The MSVC runtime is included. The
portable Windows bundle is not Authenticode signed.

Changes since 0.5.0:

- Comic reading: GPU cover transitions, wider preload choices, zoom/drag ownership,
  split wide pages and saved pan/half-page positions, portable TIFF/JPEG2000 conversion,
  notch-safe controls, and optional original-model Waifu2x enhancement.
- PDF: native text/search/outline layouts or the shared comic/DIVINA reader,
  local offline raster rendering with four quality limits, password retry without
  persistence and next-book continuation with incognito/list scope preserved.
- EPUB: continuous cross-chapter scrolling, stable CFI resume and font/flow reflow,
  nested contents, search/bookmarks/footnotes, embedded/deobfuscated and imported fonts,
  tap zones, page transitions, selected-text translation and next-book continuation.
- Downloads and cache: Android WorkManager and Windows Task Scheduler workers,
  vault credentials, resumable transfers and charging/network rules; conditional
  media/document caching, bounded memory/disk targets, and precise live cover updates.
- OCR/translation: offline native recognition, secure configurable translation providers,
  translated region overlays, optional original-model bubble grouping and private-mode
  cache exclusions. Inference runs separately from page navigation.
- Library/account tools: metadata/list editing, smart lists where supported, offline
  metadata search, ordered read-list continuation, history/statistics, password changes
  and authentication activity. Admin tools include tasks, schedules, sessions, duplicates,
  streamed log export and optional Komf identification/job tracking.

Source: `@SOURCE@`. CI verifies automated suites, isolated real Komga acceptance,
native Android/Windows integration, release builds and Windows startup before publication.
The exact Android upload is checked again for SHA256, retained certificate, package
identity, version, non-debuggable mode and 16 KiB alignment. Both uploaded application
files are checked against GitHub asset digests and `SHA256SUMS.txt`.

Full functional/visual parity and physical-device performance acceptance are still
in progress. In particular, comic curl, additional OCR models/exact typesetting,
some EPUB edge cases and OS integrations remain. See `docs/PARITY.md` and
`docs/VALIDATION.md`. This is a development preview, not the final perfect port.
Sign into a GitHub account with access to this private repository to download.
