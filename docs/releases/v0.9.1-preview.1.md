KMReader 0.9.1 fixes Kindle downloads failing with an unsendable isolate object.
Prepared books are reused between reading and offline downloads. The Windows
converter remains available briefly for subsequent jobs, and deferred note
packages no longer delay the reading resources.

Covers and page metadata load before the book download through bounded Range
requests. Kindle services now have their own settings inside the existing
Settings/Servers interface. Bundled Amazon dictionaries and their toggle are
removed; the desktop account button opens Servers directly. Dashboard date
sorts work with the local Kindle catalog.

The EPUB footer counts the full volume and opens a quick navigation menu when
pressed. Estimated logical pages are marked ~; unavailable counts no longer
appear as 0 pages. Native PDFs supply their actual page count.

Matching-edition Kindle bookmarks, highlights and notes appear in the existing
bookmarks interface. Highlights also remain visible in curl textures. Import
from Kindle is one-way: local annotation edits are not uploaded to Amazon.
Reading position retains the existing verified bidirectional synchronization.

Windows login uses the user's normal Chrome profile, with an explicit local
paste of the final address. Separate-window automatic capture remains optional.
The first KFX acquisition still requires preparation as EPUB; this build does
not promise the official Kindle app's 2–3 second first-download latency.

Streaming remains disabled. The Windows bundle includes corresponding worker
source and license notices and is not Authenticode signed. Source: @SOURCE@
