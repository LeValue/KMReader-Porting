# KMReader 0.8.13 preview

EPUB chapter loading avoids zero-width initial layout, applies reader typography
before the first iframe layout and batches formatting writes. Vertical scrolling
no longer repeatedly recreates the visible iframe's graphics layer.

Decompressed publication resources use an 8 MiB working cache. Discarded chapters
release their source DOM and serialized XHTML. Leaving curl releases its retained
GPU context, textures and embedded resources. Speculative page preparation stops
when input, settings, visibility or publication layout changes.

Curl snapshots omit offscreen prose glyphs while retaining its flow boxes.
Fragmented paragraphs and complex authored content retain the full rendering
path. Pixel comparisons cover the beginning, middle and end of long chapters,
single/double pages and LTR/RTL reading. Text resolution is unchanged.

GPU errors, context loss and interrupted preparations remove cosmetic overlays
and preserve direct navigation. Saved positions recover from collapsed native
iframes; recreated renderers initially restore text without cosmetic motion.
Animation duration follows elapsed time even when frames are delayed.
Huawei Android 10 uses hardware-accelerated hybrid WebView composition.

These are optimized release builds. Browser CPU-throttling benchmarks are
reproducible with `tool/epub_pipeline_benchmark.py`; they are not physical-device
FPS measurements. Native Windows WebView2 and Android WebView are checked in CI.
