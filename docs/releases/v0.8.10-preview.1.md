# KMReader Port 0.8.10 development preview

Curl shadows use a dense Gaussian filter instead of widely separated blur
samples, removing the repeated page silhouettes and flat brightness bands.
The shadow mask is sized for its penumbra; publication text keeps its existing
render resolution. Regression probes check receiver continuity, density,
extent and the absence of long plateaus in the shadow gradient.

Sequential curl turns reuse the previous incoming GPU texture as the next front.
Idle preparation uploads the actual current page; each next page requires only
one new upload, without lowering the publication texture resolution. These
changes apply to Android and Windows.

Android EPUBs use Flutter's texture composition path with its native fallback,
rather than forcing the expensive legacy hybrid path and an extra hardware
layer. The native gate checks actual composition parents, hardware acceleration,
text/menu interactions, vertical scrolling and visible pixels.

Windows captures WebView2 frames on a dedicated worker, preserving a leased
capture until its texture is copied. A frame is copied to the GPU only once;
callback teardown is fenced before the native texture is unregistered. Native
scrolling checks require worker delivery, advancing captures and GPU copies,
and recovery after a real renderer exit. No explicit 60 FPS limit is applied.

Install the APK for your architecture (usually ARM64), or extract the complete
Windows ZIP. Build 20 retains preview package/certificate update support.
Physical frame rates still depend on the device and system WebView runtime;
CI rendering counters do not establish 144 Hz on a physical display.
