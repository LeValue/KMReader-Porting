# KMReader 1.0.0

- Read Komga, Kindle and local libraries on Android and Windows.
- Import EPUB, PDF and comic archives. Read offline and keep your place.
- Search EPUBs and PDFs. Add EPUB bookmarks, highlights and notes, or open the
  table of contents to move around the book.
- Manage Komga metadata and covers, and upload multiple files through the
  server companion.
- Synchronize eligible Kindle EPUB positions and annotations, and send
  personal documents to Kindle.
- Update the app from Settings while keeping accounts, downloads and progress.
- Android downloads are available separately for ARM64, ARMv7 and x86_64.
