# KMReader 1.0 development previews

Stable 1.0 is still in progress. The current public package is
**[candidate 6, build 36](https://github.com/LeValue/KMReader-Porting/releases/tag/v1.0.0-candidate.6)**
for Android and Windows. See [installation](../GETTING_STARTED.md) and the
[porting checklist](../PARITY.md) for requirements and remaining work.

## Candidate 6 — build 36

### Komga administration

Administrators can now:

- Add new EPUB/PDF/CBZ/CBR files from a phone or PC to an allowed library and series folder.
- Edit volume/series metadata and change covers.
- Delete a volume after confirmation identifying the title and explaining that
  its original server file is removed for every user.

New-file upload requires the optional [Debian companion and reverse proxy](../KOMGA_LIBRARY_MANAGEMENT.md).
Metadata, covers and deletion use native Komga APIs without the companion.
Duplicate filenames are rejected; replacing an existing volume file is not supported.
Upload receipts survive restarts so an uncertain result can be checked before retrying.

The lifecycle was verified on disposable Komga 1.30.1, including nested folders,
metadata, covers, duplicate rejection and deletion. Each server administrator
must configure and validate the companion for their own installation.

### Installation and verification

Build 35 users can update from **Settings → About → App updates**. Earlier builds
can install the current Preview over the existing installation. Do not uninstall
first. Windows users must keep the complete extracted bundle.

The APK keeps the original Android signing identity and includes ARM64, ARMv7
and x86_64. The Windows bundle includes the Kindle worker, notices and corresponding
source. Windows is not Authenticode signed. Release files include `SHA256SUMS.txt`
and the public update manifest.

[Source CI](https://github.com/LeValue/KMReader-Porting/actions/runs/43638043777),
[delivery checks](https://github.com/LeValue/KMReader-Porting/actions/runs/43639902577),
downloaded packages and the public update feed passed verification.
[Detailed evidence and limitations](../VALIDATION.md) include hashes and skip counts.

## Known limits and release status

- Full functional/visual parity and physical-device acceptance are tracked in the
  [porting checklist](../PARITY.md); a green CI run does not complete that work.
- Kindle support is unofficial and currently targets Amazon.it. Personal-document
  editing excludes purchased books. EPUB state migration has
  [documented limits](../KINDLE_LIBRARY_MANAGEMENT.md), including notes/highlights,
  PDFs and editions that cannot be mapped safely.
- Local RAR/CBR reading is not implemented. CBR upload to Komga is a separate feature.
- AI/model-management and translation extensions remain future work.
