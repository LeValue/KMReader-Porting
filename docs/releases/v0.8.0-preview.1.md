# KMReader Port 0.8.0 development preview

Dashboard scrolling now clamps at its bounds with one root scrollbar and refresh
control. Independent shelf refresh wrappers are removed and loading placeholders
reserve their shelf height. A Windows-platform regression sends repeated mouse
wheel events at the bottom and verifies stable position, extent and request count.
Physical Windows GPU/frame-time acceptance is still required.

Settings forms now follow the original group order, labels, captions and
conditional controls, including the unified DIVINA reading direction, Force
Default switch, PDF vertical direction, theme swatches, scale ranges, font-weight
override and dedicated EPUB preset/font pages. Presets can be renamed. Shared
spacing, backgrounds, separators and adaptive picker rows cover compact and wide
windows. Reading statistics adds the reference's seven compact metric tiles,
weekly calendar heatmap with all seven ranges and reading-status donut.

Global reader changes now take precedence over old snapshots for the changed
fields, preserving CFI/progress and unrelated book preferences. Fresh installs
adopt original defaults; upgrades preserve existing preferences. Dashboard scope
supports multiple libraries throughout shelves, See All and selection queries.
Next-unread navigation supports older-server/local and offline-list fallback.
Comic context actions can display either spread page solo and export a full PNG
through the OS file picker without moving the parent reader or requesting broad
storage access. Saving adapts the original sharing-sheet interaction.

Use `KMReader-0.8.0-android-arm64-preview.apk` for most current Android phones;
ARMv7 and x86_64 variants are complete packages for those architectures. The
retained Preview identity and build number 10 preserve in-place updates. On
Windows 10/11 x64 extract the entire ZIP and run `KMReader/kmreader.exe`; the
bundle includes its native engines and MSVC runtime and is not Authenticode signed.

Source: `@SOURCE@`. Publication requires source-matched Android/Windows builds and
native integration, provenance, retained signing identity and asset verification.

Complete upstream parity is not claimed. Core ML catalog/model-role management,
Apple-only integrations, the simpler native HTML EPUB fallback, exact typography,
some sidebar/offline/detail layouts, swipe curl, native sharing-sheet semantics
and physical-device performance acceptance remain open. See `docs/PARITY.md`,
`docs/SETTINGS_AUDIT.md` and `docs/VALIDATION.md`.
