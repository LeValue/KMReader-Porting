# KMReader 0.8.15 preview

Comic curl stays enabled when page aspect ratios or single/double layouts change.
The outgoing front and incoming back retain their own fitted dimensions and
texture coordinates. Orthographic projection removes perspective magnification
and the previous end-of-turn geometry resize. Spreads use a stable central spine.
Stationary margins follow the reveal instead of immediately exposing a differently
sized next page. The existing EPUB renderer is unchanged.

Prepared comic frames and screen captures use the display pixel ratio. Prepared
artwork uses the live image's decode width and upscaling policy; cache keys include
display density. A bounded 64 MiB frame cache prioritizes the current/next pair on
large displays, and curved paper uses high-quality image sampling.

Bottom navigation labels retain one line with full semantic names and consistent
icon alignment, including Italian labels and enlarged text on narrow phones.

Regression checks compare native-density prepared images against live artwork,
unchanged front pixels during curl, mixed-size reveal/endpoints, and bottom
navigation at 320/360/390 logical pixels with increased text scale.
