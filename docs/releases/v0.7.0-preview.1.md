KMReader 0.7.0 development preview for Android and Windows.

This update extracts the original settings from upstream and adds working controls
for reader defaults, EPUB themes/overlays/presets/fonts, PDF presentation, separate
page/cover caches, timeouts/retries, real-time updates, translation preferences,
launcher icons, privacy and local diagnostics. Dashboard settings include section
reset, card-kind menu visibility and gradient backgrounds. Existing browse/card
preferences and the grouped iPad-style settings index are included.

Cache clearing prevents in-flight requests from restoring deleted entries and
preserves downloaded books. Independent quotas cover all configured accounts.
Turning real-time updates off now cancels pending headers and idle live streams.
Automatic deletion of completed downloads waits until the last reader releases
its files. Per-book preferences and the previous port's default behavior are
preserved during upgrades.

The source audit covers 128 persisted keys/structured fields and 227 control
declarations, including composite objects and internal state; those counts do not
mean 128 independent user-facing preferences. See `docs/SETTINGS_AUDIT.md` for the
complete mapping, source references and remaining differences.

For most current Android phones, install `KMReader-0.7.0-android-arm64-preview.apk`.
Older ARMv7 devices use `KMReader-0.7.0-android-armv7-preview.apk`; x86_64 devices
use `KMReader-0.7.0-android-x64-preview.apk`. Each APK is a complete application.
The retained Preview package/certificate and increasing build number 9 preserve
updates, accounts and downloads. For Windows 10/11 x64, extract the entire
`KMReader-0.7.0-windows-x64-preview.zip` and run `KMReader/kmreader.exe`.
The MSVC runtime is included; the Windows bundle is not Authenticode signed.

Source: `@SOURCE@`. Publication requires all source-matched Android/Windows
verification jobs, embedded provenance and the retained Android signing identity.

This is not a declaration of complete parity. Apple-only Handoff/Spotlight/Live
Activities and StoreKit are unavailable. Original Core ML catalog download and
model-role management remain partial: the portable ONNX bubble detector and
native OCR work. Native EPUB fallback is simpler than the browser engine, several
reader/default/unit choices are adapted, dashboard scope is one library or all,
and comic swipe uses slide even when discrete turns use curl. Exact typography,
translated typesetting, physical-device performance and pixel parity need further
acceptance. See `docs/PARITY.md`, `docs/SETTINGS_AUDIT.md` and `docs/VALIDATION.md`.
