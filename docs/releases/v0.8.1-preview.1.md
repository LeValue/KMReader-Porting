# KMReader Port 0.8.1 development preview

Fixes the Dashboard scrolling regression reported in 0.8.0 on Android and
Windows. Empty shelves were disposed outside the lazy vertical viewport and
recreated with tall loading placeholders when scrolling back up. Their height
corrections could move the viewport down despite upward input. The Dashboard's
bounded sections now retain their state and exact height throughout scrolling;
horizontal cover lists and unbounded catalogs/logs remain lazy.

Bounded settings forms use the same stable section scrolling. The application
uses clamped boundaries without Android stretch/glow; app bars keep consistent
elevation at the upper edge. Repaint boundaries retain section surfaces.

The Appearance language picker now fades a fixed-size menu as one retained
surface instead of collapsing its rows. The language change is applied after
the route has finished closing, preventing a whole-app localization rebuild
during dismissal. Other shared choice dialogs/sheets also defer their result
until closing finishes. Outside dismissal, keyboard Escape, checked selection
and reduced-motion preferences are preserved.

EPUB initialization and page turns now read the actual viewport geometry before
reporting readiness or navigating, and refresh the locator after layout settles.
Epub.js can complete its reporting queue before the relocation callback arrives.
Browser regressions hold both initial and turn reporting to check valid readiness
and saved positions without false reading progress.

Regression fixtures reproduce both upward Dashboard jumps and premature language
updates on the original 0.8.0 implementation. Native Android/Windows checks also
exercise the actual Appearance flow, mixed empty/full Dashboard shelves, and
settings upper-boundary pixels. These checks do not measure physical-device FPS
or every Windows graphics driver.

Install the complete APK matching your device (ARM64 for most current phones).
The retained Preview identity/certificate and build number 11 support in-place
updates. Extract the full Windows ZIP and run `KMReader/kmreader.exe`.
