# KMReader 1.0.3

- Install KMReader on Windows with a choice of installation folder, per-user
  or all-users setup, and Start menu and desktop shortcuts.
- Open the Windows window sooner by starting background services after the
  first frame.
- Include the final character in imported Kindle highlights and open linked
  notes from anywhere in the highlighted passage. Include highlight colors in
  annotation sync when the service returns them.
- Reduce background work while EPUB text settings, search or the table of
  contents is open on mobile.
- Keep the focus and hover backgrounds on catalog cards inside the scrolling
  area on the Dashboard and in the Library.
