# KMReader Port 0.8.4 development preview

Hiding EPUB controls now retains the existing native WebView instead of disposing
and reinserting its closed platform view. Text clicks, fullscreen, Escape and
viewport changes preserve the reading surface and character anchor. The comic
and EPUB fullscreen buttons now enter Windows window fullscreen; Escape restores
the window before closing the reader. F11 toggles fullscreen too.

Settings keep their section title on desktop as well as mobile. Content has a
bounded width, Dashboard section controls have consistent card/list margins,
and reader forms use a fixed title/close action with scrollable, spaced fields.
EPUB typography, appearance, reading, page-turn and tap-zone options are grouped;
font import/removal remains available. New labels are localized in all ten
supported languages.

Page turns are visible sheet transitions rather than brief small offsets. EPUB
uses Chromium compositor snapshots, with no native screenshot/JPEG bridge on
page turns. Curl deforms the sheet around a cylinder with a reflected back,
shading and shadow; comics use a textured mesh with perspective and lighting.
Slide/cover transitions support a brighter moving sheet and rounded corners.

Both readers offer animation duration, moving-page brightness, corner radius
and gesture-following options in global and in-reader settings. With gesture
following, a drag controls the page and can return to its original position to
cancel. Canceled previews do not record reading progress. Turning gesture
following off leaves a swipe that commits on release and then animates.
Reduced-motion settings retain direct navigation. EPUB's advanced sheet effects
require a View Transitions-capable WebView; older engines retain direct reading.
These are portable cylindrical sheet effects, not Apple's proprietary renderer.

Regression coverage exercises actual rendered pixels, mid-flight animation
visibility, native surface identity and fullscreen round-trips, touchscreen and
mouse gestures, cancellation, second-finger interruption, resize, RTL, typography
extremes, accessibility text sizes and both existing reading engines. The native
renderer-interruption recovery test is retained.

Install the complete APK for your device (ARM64 on most current phones). Retained
Preview identity/certificate and build number 14 support in-place updates.
Extract the full Windows ZIP and run `KMReader/kmreader.exe`.
