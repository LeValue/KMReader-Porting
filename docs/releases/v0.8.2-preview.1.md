# KMReader Port 0.8.2 development preview

Windows mouse-wheel detents now produce continuous animated scrolling in the
Dashboard, catalog, settings, offline views and application dialogs. Consecutive
detents accumulate distance and preserve velocity; reversing direction discards
the previous pending distance. Shift-wheel also animates horizontal shelves.
The destination is clamped to the available content so repeated outward input
at either boundary cannot accumulate overscroll.

Each active wheel sequence uses one Flutter ticker and a critically damped
simulation. Retargeting does not restart the ticker or rebuild application
widgets every frame. Idle views have no active animation. Catalogs, logs and
other unbounded lists retain their lazy item builders. Bounded Dashboard and
settings sections retain their stable geometry from 0.8.1.

Touch and native precision-trackpad pan gestures retain their existing behavior.
Touch, scrollbar dragging and programmatic navigation can interrupt the wheel
animation. Windows reduced-motion preferences keep immediate wheel scrolling;
Android scrolling is unchanged. EPUB WebView and paginated reader input retain
their separate gesture handling.

Regression coverage checks high-rate input while it is still arriving, velocity
continuity, direction reversal, both boundaries, nested lists, horizontal shelves,
reduced motion, interruptions, changing content and lazy construction. A Windows
native test also sends WM_MOUSEWHEEL messages through the runner/engine path and
compares content pixels at both boundaries. Native input injection exists only
in debug test builds.

Install the complete APK matching your device (ARM64 for most current phones).
The retained Preview identity/certificate and build number 12 support in-place
updates. Extract the full Windows ZIP and run `KMReader/kmreader.exe`.
