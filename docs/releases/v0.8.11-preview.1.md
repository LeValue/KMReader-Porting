# KMReader Port 0.8.11 development preview

Windows EPUBs explicitly request a positive 1ms native capture interval on
supported Windows versions. The system's default 16ms interval can deliver only
every third frame on a 144Hz display. Setting zero alone is unreliable on
affected builds; a positive interval follows the capture API maintainer's
workaround. Older systems retain the compatible capture path.

Native diagnostics read back the live interval and check successful worker
delivery. Tests on a physical RTX 2060 SUPER use the user's existing local Alice
EPUB, recording browser callbacks, native captures/GPU copies and Flutter frame
timings separately. These counters measure the rendering pipeline rather than
physical monitor presentation FPS.

The dense curl shadows, retained page textures, eased transitions and Android
texture composition from 0.8.10 remain. This release adds no new Android rendering
changes or physical Android performance claims.

Install the APK for your architecture (usually ARM64), or extract the complete
Windows ZIP. Build 21 retains preview package/certificate update support.
