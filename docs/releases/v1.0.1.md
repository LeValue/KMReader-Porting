# KMReader 1.0.1

- Keep catalog filters, sorting and smart lists available across sessions.
- Manage the download queue and keep downloaded books available offline.
- Export individual comic and PDF pages, and read EPUBs that mix reflowable
  text with fixed-layout pages.
- Open adaptive catalog details and reading panels on Android and Windows.
- Apply EPUB presets to a single book or restore the global reader settings.
- Use localized reading controls, larger text and keyboard navigation.
- Restore eligible Kindle notes and highlights when replacing personal EPUBs.
  Send documents as a separate copy when the original should be retained.
- Install the Android APK for ARM64, ARMv7 or x86_64.
