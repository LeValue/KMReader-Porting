# KMReader 0.8.12 preview

EPUB reading now reuses settled layout, text geometry and recent reading
locations instead of repeatedly scanning and formatting the chapter. Position
records are invalidated when content, fonts, images or layout change.

Curl no longer waits two extra display frames. Browser compositor
transitions retain their delivery barrier. Reader settings can open
while the browser is busy; live preference updates remain ordered.

Curl submits its GPU programs during publication layout and uses asynchronous
compilation where the driver supports it, avoiding synchronous shader-status
queries on the browser's interaction thread.

Text resolution, typography, selection, CFI positions, fixed pages and curl
shadows retain their existing verification. Windows and Android packages are
optimized release builds. Physical Android performance has not been measured.
