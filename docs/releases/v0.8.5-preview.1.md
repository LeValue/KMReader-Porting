# KMReader Port 0.8.5 development preview

Windows mouse clicks in EPUBs retain the controls and window state. Fullscreen
belongs to the explicit button or F11. Mouse press/release coordinates are sent
to WebView2 before the button state, preventing stale hits after layout changes.
Margins cannot begin a text selection, selection is cleared on empty-margin clicks or opening options, and selection reporting is coalesced. Arrow keys
and Page Up/Down work from Flutter's composition-view focus as well as book DOM
focus. Ctrl+C copies a selected passage.

Option values align with the trailing edge of their cards. Anchored choices use
the same bounded menu for short and long lists, positioned beside the source
row rather than at the window edge. EPUB options use lazy scrolling; dragging
a typography slider updates its own label/thumb and commits one reflow on
release. Modal options suspend book input and pending presentation effects.

Slide keeps the earlier sheet above the later sheet in both directions. The
lower sheet has a small parallax offset and gradually loses its dimming. Dark
upper sheets brighten subtly after the first quarter of travel with an
exponential ramp. The configured duration, corners and gesture following remain
available; release uses a smooth ease-out rather than an abrupt finish.

EPUB curl replaces the low-resolution, per-frame PNG displacement map with a
full-resolution GPU cylinder. The fold follows both horizontal and vertical
drag movement. Double-page turns retain stationary page backgrounds and use
the new left page on the back of the turning sheet. A single-page sheet has a
mirrored, translucent back. Curl ignores slide brightness/corner effects.
Textures and publication resources are bounded and nearby positions are prepared
while idle, without navigation or progress writes. Unsupported GPU/artwork paths
retain direct reading; this is a portable renderer, not Apple's implementation.
Comic curl also removes the sheet tint and follows the drag's vertical direction.

Opening an EPUB now opens and inspects its ZIP once in the resource worker.
The UI receives a navigation index and does not reopen the archive. TOC link
validation checks resource existence without decompressing every referenced
chapter. Remote progression retrieval runs in parallel with archive preparation.
The initial native layout barrier is retained: fonts, images and spread views
settle before reading is reported ready.

Install the complete APK for your architecture (usually ARM64). Preview identity,
certificate and build number 15 retain in-place update support. Extract the whole
Windows ZIP and run KMReader/kmreader.exe. This remains a development preview;
controlled native tests do not establish zero lag on every device or full parity.
