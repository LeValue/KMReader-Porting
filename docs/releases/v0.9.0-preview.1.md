KMReader 0.9.0 integrates an Amazon.it account into the existing library,
download queue, book details and reader. Connect it from the welcome screen or
Settings. Windows can import the personal prototype's existing session once;
Android signs in with Amazon in its login window.

Downloaded personal documents are prepared by an on-demand worker outside the
reader process. On Android the worker exits after use. Prepared EPUB/PDF files
remain available offline; original-position markers preserve exact Unicode
positions wherever the converted text matches the source. Resume and queued
Kindle position updates check the publication edition and verify server writes
by reading back. Incognito reading does not synchronize positions. Amazon
catalog dictionaries are hidden by default and can be shown in Settings.

The duplicate Search destination is removed from mobile and desktop navigation;
search remains in Library.

Streaming is experimental and is not enabled in this build: partial transfer
and text/position decoding have been tested, but faithful progressive layout has
not been verified. Protected files which the reader cannot prepare are reported
as unsupported. Kindle downloads currently use the app's foreground queue;
existing Komga background downloads are unchanged.

The converter's corresponding source and license notices accompany the portable
Windows build. The Windows bundle includes the MSVC runtime and is not
