# KMReader 1.0.2

- Use a consistent dark palette across Android and desktop. Wide layouts use a
  thin divider between the sidebar and the catalog.
- Resize the Windows window down to 720 × 520 logical pixels.
- Open and close mobile reader panels with animations that respect the system
  reduced-motion setting. EPUB pages retain their layout while the panel moves
  and while the keyboard is open.
- Keep the reading position in vertically written EPUBs when changing the font
  size after a page turn in continuous mode.
- Install the Android APK for ARM64, ARMv7 or x86_64.
