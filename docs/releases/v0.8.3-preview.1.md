# KMReader Port 0.8.3 development preview

EPUB page turns no longer capture a native screenshot, encode it as JPEG and
send it back to the browser for every animated page. The reader animates its
live viewport with an interruptible compositor effect; navigation commits
before that cosmetic effect finishes. Rapid input cancels the preceding effect
instead of waiting behind its duration. Reduced motion disables the effect.

New chapters still wait for their layout, fonts and images. Already settled
chapters avoid repeated layout waits on every page. Reader mutations, including
resize, navigation, font changes and late resource reflow, execute in order.
Delayed coarse location reports retain the committed character CFI, including
large vertical text. The native WebView widget remains mounted across locator
updates. Windows avoids redundant composition-surface resets at unchanged sizes.

Windows WebView2 and Android renderer interruptions recreate the browser and
restore the saved reading position, with a bounded automatic retry count and a
manual retry action. Windows screenshot responses with missing/malformed data
return an unavailable image rather than throwing across a native callback.
This covers renderer interruption; it does not recover an OS-terminated app.

Catalog card options now reuse one small in-memory snapshot, invalidated when
settings change, instead of reading and decoding SQLite values for every card.
Existing bounded cover/page caches, network request coalescing, foreground
priority, background JSON/EPUB parsing and continuous Windows wheel scrolling
remain covered by regression checks.

The performance report includes reproducible browser command benchmarks and
memory/visible-pixel stress checks. These are not physical-device FPS results.
Native default EPUB tests exercise rapid page turns and rendered text on both
platforms; Windows additionally exercises an actual WebView2 renderer crash.

Install the complete APK matching your device (ARM64 for most current phones).
Preview identity/certificate and build number 13 preserve in-place upgrades.
Extract the complete Windows ZIP and launch `KMReader/kmreader.exe`.
