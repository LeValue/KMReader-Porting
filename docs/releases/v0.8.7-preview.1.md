# KMReader Port 0.8.7 development preview

Comic curl uses a fold-aligned mesh, separate front/back textures in spreads,
and soft edge shadows that never fill an intersecting folded outline. The
stationary leaf stays in place and odd final spreads retain their blank cell.
A bounded cache prepares the current and neighboring comic frames while idle;
warm turns start without a screen readback or changing the live page during a
cancelable gesture. Cropped, rotated, zoomed and split pages retain snapshot
fallbacks. Commands and gestures beyond the first/last page do not animate.

Comic and EPUB controls float over an unchanged reading viewport and disappear
after inactivity. Touch the central controls zone to reveal them; on Windows,
move the pointer near the top/bottom or use Escape. Extra actions live in the
more menu; Windows retains its explicit fullscreen button and F11.

EPUB text settings build individual visible rows. Typography changes are saved
while the panel is open and applied together when it closes, avoiding repeated
browser reflow beneath a scrolling panel. Slide/cover update compositor
transforms directly. Windows WebView capture uses three buffers and presents
the latest queued capture; frame-limit comparisons retain submillisecond precision.

**Local Books / Libri locali** is a dedicated section, also available from the
welcome screen without a Komga account. Import EPUB, PDF and CBZ/ZIP files;
originals are copied into app storage, deduplicated by content, and can be read
offline with persistent progress independent of the Komga sync queue. Removing
an imported book preserves the source file. Local raster sources bypass the
server offline-first download gate. RAR/CBR is not supported by this
initial local importer.

Removed moving-page lightening, curl-reach and moving-page corner controls from
both readers and global defaults; legacy cosmetic overrides are ignored.

Install the APK for your architecture (usually ARM64), or extract the complete
Windows ZIP. Build 17 retains preview package/certificate update support.
Controlled checks do not establish frame rates on every physical device.
