# KMReader Port 0.8.9 development preview

EPUB curl casts one continuous shadow onto both the stationary page and the
flat part of the turning sheet. The shadow no longer stops at the spine.
Its stronger density and broader penumbra follow the Apple Books reference.
The existing geometry projection, reusable mask and GPU blur remain.

Automatic EPUB slide/cover transitions use browser compositor animations with
a compatibility fallback. Their final movement eases into rest; drag release
retains the gesture's velocity. Gradual shade and moving-edge shadows return
to slide/cover, with clear original artwork at both endpoints.

Automatic curl and comic page motion start from the displayed position and
pace delayed frames instead of catching up in one large position jump.
Comics retain the native release spring with the same delayed-frame handling.
A contact can interrupt an automatic turn and still settle onto a complete page.
Curl pipelines and framebuffers warm while idle; retained texture uploads and
canvas dimensions avoid redundant work before an automatic turn.

Flutter page captures now begin on the raster thread, avoiding a worker-thread
EGL context conflict observed during native pixel validation on Android.

Windows also preserves native PDF password errors, allowing protected books to
show the password prompt and retry instead of a generic loading failure.

Single-page fixed-layout EPUBs retain a valid page reference and accept the first
turn even when the native view has not delivered its viewport mapping yet.

Install the APK for your architecture (usually ARM64), or extract the complete
Windows ZIP. Build 19 retains preview package/certificate update support.
Local formats remain EPUB, PDF and CBZ/ZIP. Physical frame rates vary by device.
